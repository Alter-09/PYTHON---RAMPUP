# Lab 01: Data Wrangling Clinic
A standard-library Python application that processes sales CSV data and customer JSON records using `pathlib` to generate a formatted sales summary. 
## Requirements
* **Python 3.11+**
* **No external dependencies** (uses standard library `csv`, `json`, and `pathlib` only)
## Execution 
Run the main script from the root directory:
```bash
python3 sales_report.py
